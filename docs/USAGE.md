# 使用指南

## 启动与首次授权

从源码构建后，应用位于 `build/OpenPaste.app`，双击即可打开。构建步骤见[开发指南](DEVELOPMENT.md)。应用使用珊瑚橙底色与奶白色 P 叠页 Logo，菜单栏显示同款单色 P 标记，应用不显示 Dock 图标。

```sh
./scripts/run.sh
```

在其他应用复制内容后，按 **⌘↑** 打开历史，再按一次收起；面板打开时也可按 **⌘↓** 关闭。面板从鼠标所在屏幕的底边向上滑出，覆盖屏幕全宽；关闭时向下收回并淡出，回车或双击粘贴也使用相同的收起动画。系统开启“减少动态效果”时改用淡入淡出。

在 **设置 → 常规 → 唤起快捷键** 中点击快捷键按钮，然后按下新的组合键即可立即保存。支持 Command / Option / Control / Shift 与字母、数字、空格、方向键、功能键等组合，至少包含 Command、Option、Control 中的一个。按 Esc 或点击其他位置取消录入，可一键恢复默认。无法注册时不会覆盖原设置；旧版本保存的自定义快捷键和预设会自动迁移。恢复默认会使用 ⌘↑。设置窗口保持显示，唤起快捷键只打开或收起面板；从设置唤起再收起面板后，焦点回到设置窗口。

首次直接粘贴时会提示辅助功能权限。在 **系统设置 → 隐私与安全性 → 辅助功能** 中允许 OpenPaste 后，即可向原来的应用发送粘贴快捷键。不授权也能正常记录、搜索和复制，再手动按 ⌘V 粘贴。

需要长期使用或开启登录启动时，建议先退出应用，把 `OpenPaste.app` 移到固定的应用程序目录，再启动和授权。构建脚本会复用固定的本机签名身份，更新时保持 Bundle ID 和签名身份一致，避免每次编译都使辅助功能授权失效。从旧版临时签名首次切换时，需要重新授权一次；若开关已打开但仍无法直接粘贴，请在辅助功能列表中移除旧的 OpenPaste，再添加当前应用并允许。

本机签名未经过 Developer ID 公证，适用于这台 Mac 上的本地构建；分发给其他用户时应使用固定的 Developer ID 身份签名。

## 功能与快捷键

- 文本、链接、图片、文件引用的历史记录，显示来源应用与复制时间。
- 保存系统提供的文本、RTF、RTFD、HTML、PNG、TIFF、JPEG、URL 等格式；恢复时写回原格式。
- 屏幕底边全宽卡片面板，上滑展开、下滑收起，适配多屏幕与减少动态效果。
- 搜索当前分组中的内容、来源应用及类型，支持中英文类型关键词。
- 顶部横向分组，与搜索框同一栏；默认“全部记录 → 收藏 → 自定义分组”，可鼠标点击或 ⌘← / ⌘→ 循环切换。
- 内置“收藏”自动汇总所有星标内容，保留内容原有分组，取消星标后自动移出收藏。
- 自定义分组、右键操作和内容预览。
- 相同内容和格式去重，再次复制时移到最前，保留收藏和分组。
- 粘贴历史记录后更新最近使用时间并移到最前，保留原始创建时间、来源、收藏、分组及格式；支持纯文本粘贴。
- 暂停记录、应用 Bundle ID 排除列表、常见敏感/临时剪贴板标记过滤。
- 7/30/90 天或不按时间清理；最多 1,000 条普通历史。收藏和分组内容不自动清理。
- 自定义全局快捷键录入、立即生效、持久保存、取消录入与恢复默认。
- 辅助功能权限引导、自动粘贴、纯文本粘贴、登录启动设置。

| 操作 | 快捷方式 |
| --- | --- |
| 打开/关闭面板 | 默认 ⌘↑，再次按下可关闭，可自行录入组合键 |
| 收起面板 | ⌘↓ 或 Esc |
| 循环切换分组 | ⌘← / ⌘→ |
| 选择内容 | 单击、左右/上下方向键 |
| 粘贴所选内容 | 回车，或双击卡片 |
| 粘贴为纯文本 | ⇧⌘回车，或右键菜单 |
| 快速粘贴前九条 | ⌘1–9 |
| 预览 | 空格打开，回车直接粘贴预览内容；再按空格或 Esc 关闭；也可使用右键菜单 |
| 搜索 | ⌘F |
| 删除所选记录 | Backspace（⌫）、Delete 或 ⌘⌫；编辑搜索框时仅用于删字，空搜索框也不会删除卡片 |
| 设置 | ⌘,，或齿轮按钮 |
| 关闭/返回原应用 | Esc |
| 菜单栏快捷菜单 | 右键菜单栏图标 |

鼠标单击卡片立即选中，不等待双击判定，也不自动滚动居中；双击仍用于粘贴。键盘方向键选择继续自动滚动到选中卡片。

点击面板外的桌面、其他应用或屏幕其他区域会自动收起面板；尺寸预览时，点击设置窗口内可继续调整，点击窗口外才收起。方向键用于浏览卡片时会退出搜索编辑，将焦点留在卡片区并保留搜索词；仅输入文字、点击搜索框或按 ⌘F 时进入搜索。

面板每次打开时默认不聚焦搜索框，可直接用方向键选择、退格删除卡片。直接打字会自动聚焦搜索框，首个按键会一同输入，并在已有搜索词后继续输入；也可点击搜索框或按 ⌘F 开始搜索。编辑搜索框时，退格只用于删字，关键词删空后继续按退格也不会删除卡片；点击卡片、离开搜索编辑后，才可用删除键删除所选记录。也支持选中后粘贴文本到搜索框。

删除时卡片会缩小淡出，其余卡片平滑补位；选中状态优先移到右侧相邻卡片，删除末尾卡片时移到左侧，删除未选中的卡片则保留原选择。相邻关系按当前分组和搜索结果计算，不会跳回第一条；仅在需要时滚动以露出新选中的卡片。开启“减少动态效果”时使用短暂淡出。

搜索框可直接输入类型关键词，英文不区分大小写：

| 类型 | 支持的关键词 |
| --- | --- |
| 图片 | 图片、图像、照片、img / imgs、image / images、pic / pics、picture / pictures、photo / photos |
| 文本 | 文本、文字、纯文本、text / texts、txt |
| 链接 | 链接、网址、超链接、link / links、url / urls、hyperlink / hyperlinks |
| 文件 | 文件、文档、file / files、doc / docs、document / documents |

类型词以空格分隔，可与内容或应用名组合，例如 `img Safari` 只显示内容或来源应用匹配 Safari 的图片，`文件 合同` 只显示匹配“合同”的文件。多个类型词表示任选其中一种，例如 `img link` 显示图片和链接。类型筛选与当前分组、收藏同时生效；清空搜索后恢复当前分组的全部内容。只识别完整类型词，`image.png`、`myimage` 和网址仍按普通内容搜索。

⌘← / ⌘→ 按顶部标签顺序，在“全部记录”、“收藏”和自定义分组之间循环切换，并保留当前搜索词。点击分组右侧的 + 会在原位展开名称输入栏，自动聚焦；点击名称左侧的图标可从图钉、文件夹、工作、生活、灵感、阅读、代码、链接、图片、喜欢、快捷和标签中选择。回车创建，点击别处也可保存有效名称，Esc 取消。未输入或只有空白字符时不创建分组。选择图标后会自动填入并选中对应名称，例如工作图标填入“工作”，用户可直接改写或删除；清空后不会自动补回，名称为空时不创建分组。图标随分组保存在本机，旧分组沿用图钉。右键分组可删除分组并保留其内容。搜索框中已有文字时，普通左右方向键用于编辑搜索词；普通上下键仍可选择卡片。中文输入法正在选词时，空格、方向键、回车和 Esc 由输入法处理，确认选词后再按回车才会粘贴卡片。分组命名时按键交给名称输入栏；预览和设置窗口保留各自的输入行为。

## 拖拽与显示大小

拖动时使用 156×54 的小预览，保持 65% 不透明度。图片显示缩略图，其他内容显示类型图标与标题，减少对目标分组的遮挡。

按住卡片拖到顶部的分组标签，目标标签会高亮，松开后移入该分组并切换到目标分组。拖到“收藏”会添加星标、保留原有分组；拖回“全部记录”会取消自定义分组归属、保留星标。文本、链接、图片和文件引用均可归类。

在 **设置 → 常规 → 面板与卡片大小** 中选择“较小 / 标准 / 较大”。默认“标准”，同步放大面板高度、卡片和内容字号；较矮屏幕会限制面板高度，避免超出屏幕。

大小使用“较小 / 标准 / 较大”三个并排选项。调整时自动显示底部面板，设置窗口保留焦点，可连续切换尺寸比较实际效果。点选选项、临时焦点变化或菜单关闭不会收起预览；点击设置窗口外部、切换应用、关闭或最小化设置后才收起，所选大小继续保存。尺寸预览期间卡片不接收鼠标操作，避免比较大小时误触粘贴。
