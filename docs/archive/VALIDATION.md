## 面板 Logo 与应用图标一致

主面板标题旁的 Logo 改为直接显示完整应用图标，使用原始颜色，保留珊瑚橙底色、奶白 P 与半透明叠页；不再使用蓝色着色的菜单栏单色模板。与设置页共用 `NSApp.applicationIconImage`。

验证：release 构建及严格签名校验通过，应用已重启；本机主面板截图确认左上角显示完整橙色 Logo，图标及标题布局正常。本次仅调整图像显示，未重复运行自动测试。

## 珊瑚橙 P 叠页 Logo

应用图标改为珊瑚橙渐变底色、奶白色 P 与半透明叠页，同一矢量轮廓生成菜单栏的单色 PDF 模板。主面板使用相同 P 标记，设置页直接显示应用图标；暂停记录时保留原暂停状态图标。构建脚本会在生成器更新或图标资源缺失时重新生成并复制两类资源。

验证：全部 65 项现有测试通过；release 构建、Info.plist 检查及严格签名校验通过。检查 16 / 32 / 128 / 512 px 图标及黑白菜单标记的离屏预览（`build/logo-qa.png`），小尺寸轮廓可辨识。应用已重启，设置窗口实测显示新图标。未切换系统深浅色外观验证菜单栏实际着色，单色标记使用 AppKit 模板图像机制。

## 默认聚焦卡片操作

移除主面板首次出现和每次唤出时对搜索框的主动聚焦。面板显示后将 first responder 设为面板本身，避免 AppKit 恢复上次搜索编辑器；默认可直接选择、删除卡片。直接输入文字、死键或输入法内容时仍同步聚焦搜索框并传递原始事件，点击搜索框和 ⌘F 仍可主动搜索。Backspace 和 Delete 不再触发搜索聚焦。面板唤出与搜索聚焦使用独立通知，保留重新唤出时清除滚动指示条的行为。

验证：58 项自动测试通过，包括首字符完整追加、死键路由、输入法组合保护、搜索清空后的删除保护及两种删除键不触发搜索聚焦。release 应用已重新构建，严格签名校验通过。本次未对用户历史执行删除操作；主面板唤出焦点未另做界面实测。

## 搜索框删除键保护

删除卡片的键盘路由仅在未编辑文本时生效，不再根据搜索词是否为空放行。搜索框获得编辑焦点后，Backspace、Delete 和 ⌘⌫ 均交给原生编辑器；清空关键词后继续按删除键不会删除卡片。点击卡片离开搜索编辑后，仍可使用删除快捷键。此规则替代下文早期版本中“空搜索框可删除卡片”的行为。

验证：58 项自动测试通过（数据库 8 项，应用 50 项）。更新删除键路由测试，覆盖两种删除键及修饰键的编辑保护；新增原生 NSTextField 回归测试，删除最后一个字符后继续退格仍由编辑器处理，失焦后才恢复卡片删除路由。测试使用独立窗口，不操作用户历史。release 应用已重新构建，严格签名校验通过。

## 0.5.3：更新后保持辅助功能授权的签名身份（当前版本）

旧构建使用 `codesign --sign -`，其 designated requirement 绑定内容哈希，每次编译都可能使旧授权无法匹配。现在 `build.sh` 调用 `sign-app.sh`，默认复用当前用户专用的自签名证书及独立钥匙串，签名身份保存在源码和构建目录之外。保持原 Bundle ID；不修改证书信任设置或系统权限，不使用仅检查 Bundle ID 的宽松身份要求。支持显式指定 Apple 签名身份，指定无效身份或临时签名时直接失败。

验证：`./scripts/test-signing.sh` 在临时应用副本中修改版本元数据，确认两个版本内容哈希不同、designated requirement 相同，并分别通过对方的身份要求；同 Bundle ID 的临时签名副本无法通过该要求。重复运行复用相同证书；无效签名配置失败且不回退。源码与用户历史未被签名测试修改。钥匙串目录权限为 700，钥匙串和解锁凭据为 600，签名后自动锁定专用钥匙串。

57 项 Swift 测试通过（数据库 8 项，应用 49 项）。验证时发现已有粘贴时间测试用精确相等比较 SQLite Double 往返后的 Date，偶发产生约 0.12 微秒误差；该测试改为允许 1 微秒误差，保留排序、持久化和元数据断言，应用逻辑未改变。release 构建、plist、严格签名和压缩包完整性检查通过，新版已从原构建路径重新启动。

从旧临时签名切换到固定证书后仍需用户授权一次；本次验证未替用户更改辅助功能权限，也未将实际授权后跨更新的 TCC 行为记为实测通过。身份一致性依据 [Apple TN3127](https://developer.apple.com/documentation/technotes/tn3127-inside-code-signing-requirements)。

产物：`build/iPaste.app`、`build/iPaste-0.5.3-macOS-arm64.zip`。

## 粘贴旧记录更新时间与排序

所有粘贴入口共用 preparePaste，在成功恢复内容到剪贴板后更新原记录的 updated_at 并重新排序，保留原始创建时间、来源、收藏、分组、缩略图与完整 payload，不新增副本。纯文本粘贴只改变写入剪贴板的格式；未授权自动粘贴时的手动粘贴回退同样更新最近使用时间。普通复制操作沿用原排序；无法恢复内容时不更新时间。

验证：57 项自动测试通过（数据库 8 项，应用 49 项）。新增验证旧记录置顶且不增加数量、时间与排序跨数据库重启保留、来源与收藏分组保持、纯文本粘贴保留原始富文本 payload、搜索与分组状态保留、不支持的纯文本粘贴不清空测试剪贴板或更新时间、普通复制不改变排序，以及已删除记录不会被重建。应用测试全部使用临时数据库及命名测试剪贴板；本次未向第三方应用发送实际粘贴。release 构建及签名校验通过。

## 卡片单击响应

把单击和双击改为同一个普通父级手势内的并行识别，单击立即选择、双击执行一次粘贴；子级收藏按钮保留自己的点击处理。实现参考 [Apple SimultaneousGesture 文档](https://developer.apple.com/documentation/swiftui/simultaneousgesture)。鼠标选择使用无动画事务并保留卡片位置，键盘导航继续居中，删除后的相邻选择继续仅做必要滚动。

验证：51 项自动测试通过（数据库 6 项，应用 45 项），新增鼠标、键盘、删除选择来源切换测试。独立测试应用使用相同 ShelfView 和 ClipboardStore，系统双击间隔为 0.5 秒时，三次选中状态发布分别在 mouseUp 后 0.66 / 0.48 / 1.10 毫秒发生；这是模型状态更新时间，不是屏幕像素呈现耗时。界面确认双击只触发一次粘贴回调，点击另一张卡片的收藏按钮保留原选择，拖入收藏成功且未触发粘贴；仅使用临时测试记录，未写入系统剪贴板。release 构建与签名校验通过。旧系统与触控板输入未另行实测。

## 删除过渡与相邻选择

删除使用 0.24 秒缩小、向下轻移和淡出过渡，其余卡片随布局平滑补位；减少动态效果时改为 0.12 秒淡出。成功删除后直接更新内存记录，按删除前的当前可见列表选择右邻，末尾选左邻，最后一条删除后清空选择；删除未选中卡片不改变原选择。删除导致的选中变化仅做必要的滚动，普通导航保留居中行为。

验证：50 项自动测试通过（数据库 6 项，应用 44 项）。新增 5 项使用独立临时数据库、禁用剪贴板监测的实际 Store 测试，覆盖中间/首项/末尾/最后一项删除、连续删除、删除非选中项、分组与搜索共同过滤，以及数据库同步和恢复普通导航滚动状态。独立预览应用使用相同的 ShelfView 和 ClipboardStore，实测删除第 3 张后选中第 4 张，连续删除到末尾后选中左侧第 2 张，卡片补位且没有跳回第一张。本次删除验证未操作用户历史。release 构建及应用签名校验通过；旧版 macOS 和减少动态效果开关未额外实测。

## Backspace 删除、分组图标与搜索提示颜色

选中卡片或空搜索框中可用 Backspace、Delete、⌘⌫ 删除当前记录；搜索有文字、分组命名、输入法组合和预览期间保留各自的编辑行为。按住删除键不会连续删除多条记录。

新建分组提供 12 个图标选项，名称编辑与图标菜单共用一个编辑区域；切换图标不会提交名称。图标保存到 SQLite，旧数据库自动增加带图钉默认值的图标列。搜索提示改为独立的原生标签，避免共享 field editor 失去焦点后把占位文字画成正文颜色；输入法组合文字出现时也会隐藏提示。

验证：45 项自动测试通过（数据库 6 项，应用 39 项），包括旧分组迁移与图标重启后读取、删除键路由、图标菜单不提交名称，以及输入法组合时的提示显隐。release 构建和应用签名校验通过。本机界面确认新建分组时搜索提示保持浅灰，空名称和已输入名称时切换图标后均能继续编辑，名称框 Backspace 删字，Esc 取消；搜索 `18` 后全选退格只清空搜索。

首次菜单实测期间意外触发了名称提交，随后退格验证误删一条图片。已从写前日志恢复该记录的完整原始行，并清理测试分组；最终将全部 8 条历史记录和分组与验证前快照逐项比较，完全一致。恢复用临时快照已移除。最终版本重新实测菜单切换不再提交名称。深色外观、旧版 macOS 和 VoiceOver 未实测。

## 预览高度与空格切换修复

预览改为当前面板内的覆盖层，宽度最多 700 pt、高度最多 500 pt，且始终受面板实际宽高限制，四周保留 16 pt。内容过长时在预览内部滚动，不再通过系统 sheet 改变主面板的位置。预览期间暂停底层点击和搜索键盘路由；再次按空格、Esc、完成或点击预览外侧均可关闭，按住空格不会因键盘连发反复切换。收起面板同时清除预览状态。

验证：40 项现有自动测试通过；release 构建及 `codesign --verify --deep --strict` 通过。重启新版应用后，本机界面确认预览完全位于当前面板内、底层卡片布局保持，连续按空格依次打开、关闭、重新打开，Esc 返回卡片列表。未额外实测小屏幕、其他显示大小和图片预览。

日期：2026-11-05。工具链：Swift 6.4 / macOS Command Line Tools，Apple Silicon。

## 自动测试

运行 `./scripts/test.sh`，使用命名测试剪贴板和临时数据库，不读取或修改用户的普通剪贴板。

共 11 个测试方法，其中敏感标记测试包含 3 个参数化用例：

- 中文、多行、NUL 字符和富文本格式持久化，重新打开数据库后恢复。
- 重复内容提升排序，同时保留原始创建时间、收藏和分组。
- 历史期限和条数清理保留收藏及分组记录。
- 清空普通历史保留已保存内容。
- 删除分组保留内容，删除记录后无法恢复已删除的 payload。
- 内容指纹区分格式及剪贴板条目边界，不依赖同条目内的格式排列顺序。
- 真实 NSPasteboard 的纯文本及 HTML 捕获、数据库往返、写回剪贴板。
- Concealed / Transient / AutoGenerated 三种标记跳过记录。
- 超过 20 MB 的内容跳过记录。
- URL 类型识别。
- PNG 原始字节保留，生成缩略图并识别尺寸。
- 多文件引用保留独立条目边界。
